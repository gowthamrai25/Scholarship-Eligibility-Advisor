# 🎓 Scholarship Eligibility Advisor — AI Expert System

An intelligent rule-based **Expert System** built using HTML, CSS, and JavaScript that determines scholarship eligibility for students using **Forward Chaining** inference, modeled after **MYCIN**.

## 🏗️ Expert System Architecture

This project implements all 5 components of an Expert System:

1. **Knowledge Base** — 10+ IF-THEN rules for scholarship eligibility
2. **Inference Engine** — Forward chaining logic that evaluates rules against user inputs
3. **Working Memory** — Stores facts entered by the user during the session
4. **Explanation Facility** — MYCIN-style "WHY" justification for each recommendation
5. **Knowledge Acquisition Module** — Dynamically add new rules to the knowledge base

- Heuristics & Confidence Scoring
- Explanation Facility (MYCIN-style)

## 🚀 How to Run

Simply open `index.html` in any modern web browser. No server or backend required.

## 🖥️ How to Use

1. Fill in student details (name, income, marks, attendance, etc.)
2. Click **⚡ Check Eligibility**
3. Watch the inference engine fire rules with animated traces
4. See eligible scholarships with confidence scores
5. Click any scholarship for a MYCIN-style "WHY" explanation
6. Add new rules using the Knowledge Acquisition panel
